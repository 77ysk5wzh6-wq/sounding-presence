# Sounding Presence

손의 움직임과 연속적으로 반응하는 소리 및 시각적 형태를 통해 실체감을 탐구하는 웹 기반 인터랙티브 작업입니다.

## Experiences

- `hand-sweep/` — 물, 연필, 하프, 바람 장면을 손동작으로 연주하는 공간 음향 경험
- `presence-glass/` — 인트로, 물, 하프 장면을 손동작으로 변화시키는 시각 경험

두 경험 모두 카메라를 사용하므로 HTTPS 환경과 카메라 권한이 필요합니다. Chrome 또는 Safari의 최신 버전과 이어폰 사용을 권장합니다.
